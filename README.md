Asegúrate de tener instalados los siguientes componentes antes de iniciar:

- [Node.js](https://nodejs.org/) (Versión recomendada: LTS)
- [Git](https://git-scm.com/)
- Aplicación **Expo Go** instalada en tu dispositivo móvil (iOS / Android).

## 🚀 Instalación y Ejecución

Sigue estos pasos para obtener una copia local y probar la aplicación:

### 1. Clonar el repositorio e instalar dependencias

```bash
git clone <tu-repo>
cd my-app-Tayra
npm install
```

### 2. Configurar Variables de Entorno

Renombra el archivo `.env.example` a `.env.local` (o `.env`) y completa las variables de entorno necesarias:

```bash
cp .env.example .env.local
```

### 3. Iniciar el servidor de desarrollo

```bash
npm start
```

### 4. Ejecutar en dispositivo

Una vez que el servidor esté corriendo, tendrás varias opciones:

- **Android:** Presiona `a` en la terminal para abrir la app en un emulador de Android.
- **Dispositivo Físico:** Escanea el código QR que aparece en la terminal utilizando la aplicación **Expo Go** en tu teléfono.

## 🛠️ Stack Tecnológico

Este proyecto fue construido utilizando herramientas modernas y robustas:

- **Expo (SDK 54):** Framework principal para desarrollo.
- **React Native:** Construcción de la interfaz móvil.
- **TypeScript:** Tipado estático para un código más seguro y escalable.
- **React Navigation:** Gestión de rutas y navegación fluida en la app.
- **Servicios Backend:** Firebase (módulos de Authentication y Cloud Firestore).
- **Librerías de Soporte:** React Query (estado asíncrono), AsyncStorage y Expo Symbols.
