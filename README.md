# 🛍️ My App Tayra

**Descubre productos de forma fácil, rápida y organizada**

Una aplicación móvil intuitiva para explorar y buscar productos por categorías, marcas y etiquetas.

---

## 🚀 Instalación y Ejecución

### 1. Clonar y instalar dependencias

```bash
git clone <tu-repo>
cd my-app-Tayra
npm install
```

### 2. Iniciar el servidor

```bash
npm start
```

### 3. Ejecutar en dispositivo

- **Android:** Presiona `a` en la terminal

O escanea el código QR con **Expo Go** en tu teléfono.

---

## 🛠️ Stack tecnológico

- **Expo** 54 – Para Android
- **React Native** – Interfaz móvil
- **TypeScript** – Código seguro y robusto
- **React Navigation** – Navegación fluida
